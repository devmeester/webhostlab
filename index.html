Sobre o projeto

WebHost Lab · WebCore Solutions

O WebHost Lab é um laboratório de administração de servidores criado para simular a infraestrutura de uma pequena empresa que precisa hospedar sites institucionais e aplicações internas. Antes, os arquivos ficavam em computadores pessoais, sem controle de acesso, monitoramento ou backup. Aqui, eles passam a ficar centralizados num servidor local, organizado e protegido.

O ambiente roda numa máquina virtual chamada WEB-SRV01, com Windows Server, e usa o IIS (Internet Information Services) para publicar este site. O servidor também conta com um banco de dados MySQL, instalado para dar suporte a futuras aplicações dinâmicas da empresa.

O projeto também aplica medidas básicas de segurança, como firewall liberando apenas as portas necessárias, permissões NTFS na pasta do site, monitoramento por logs e rotinas de backup do site e do banco de dados. Todos os testes são feitos em rede local, sem expor o servidor à internet.

Desenvolvido por Kainã como projeto da disciplina Server and Data Center Administration, UniFECAF.
